# Garry Bakat Portfolio

A responsive software development portfolio implemented with HTML, CSS, and vanilla JavaScript.

## Features
- Responsive layout
- Day/night theme toggle with saved preference
- Animated sections with reduced-motion support
- Simulated terminal
- JSON formatter and minifier
- Insertion-sort visualizer
- Colour picker and HEX copier
- PNGID demo link

## Run locally

From this directory:

    python3 -m http.server 8000

Open:

    http://127.0.0.1:8000

## Before publishing
1. Replace the images in `images/` with your own JPEG files.
2. Update `CONTACT_EMAIL` in `js/main.js`.
3. Verify project descriptions and only claim skills you can demonstrate.
4. Test the PNGID link and all interactive features.
